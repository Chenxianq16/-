# CET6 精听

学习数据使用 IndexedDB 保存，容量不再受 localStorage 的小额度限制。首次打开会先确认旧作答、圈画、错题与设置已写入数据库，再移除同名旧副本释放空间；不会通过清空记录来处理容量不足。数据库不可用时回退到 localStorage，两个方式均不可用时明确提示失败。
五套阅读共 150 题已内置核对后的参考答案，提交本篇后自动判分并收录答错且已作答的题目，无需手动录入答案。升级时也会为此前已提交的作答补收错题。只有持久写入成功后才显示“已收藏错题”。导出进度也包含阅读错题、作答、笔记和圈画。

API 设置支持 DeepSeek / OpenAI 兼容的直连根地址、`/v1` 地址与完整 Chat Completions 地址，并自动识别误填到直连栏的 `/api/analyze` 代理地址。设置中的“测试连接”显示具体错误，不输出密钥。
现有 Worker 已支持带长度校验的 `chat` 请求，用于写作、翻译、同义词辨析和每日复盘，原听力请求格式继续保留。
阅读题可逐题加入错题本，并从阅读页的错题本入口返回题目；手动记录错因时修正策略为选填。存储失败会明确提示，不再显示保存成功。
单词跳转保留短语中的空格，未收录词查询普通释义；不会用词库第一项冒充查词结果。

## 功能

- 整篇训练：盲听完整篇章，再完成该篇章对应的选择题。
- 逐题训练：按长对话、篇章、讲座/讲话筛选并逐题作答。
- 自由跳转：盲听、答题、逐句默写和复盘可随时切换。
- 篇章复盘：查看答题与逐句结果，点击任意句子回到默写。
- 逐句默写：可无限重听，提交前隐藏原文与中文。
- 词级对照：标出写对、写错、漏写和多写的词，并计算匹配率。
- 双维错因：AI 给出“听力识别/词汇/语法/逻辑/注意力/拼写”等标签，
  用户可确认“其实认识 / 确实不认识 / 不确定”。
- 错因记录：仅在加入错词本时选择错误原因；重点语法与固定搭配也可收藏。
- 复盘高亮：错词本中的单词和搭配会在复盘中用黄色荧光笔标出。
- 全文查词：题目、原文、例句和搭配中的英文词均可点击查看释义并收藏。
- 复盘点听：直接点击复盘中的任意句子即可播放对应音频。
- AI 讲解：复杂句结构、固定搭配、选项依据和重点词。
- 本地记录：进度、答题结果和错词保存在当前浏览器。
- 低成本：前端为纯静态站点，只有 AI 请求经过 Serverless 代理。

## 本地运行

```powershell
npm run serve
```

打开 `http://127.0.0.1:8080`。本地服务器支持音频 Range 请求，逐句跳转
不需要预先生成切片。

听力音频以 48 kbps 单声道 MP3 提供，并由 Cloudflare 静态资源域名分发，
用于缩短首次播放等待时间。

```powershell
npm test
npm run validate:data
```

## DeepSeek AI 代理配置

DeepSeek API Key 不能放进浏览器。先将 `worker/` 部署到 Cloudflare Workers：

```powershell
cd worker
npx wrangler login
npx wrangler secret put DEEPSEEK_API_KEY
npx wrangler deploy
```

模型默认使用 `deepseek-chat`。随后在网页右上角的
“AI 设置”中填写 Worker 地址，例如：

```text
https://cet6-listening-ai.<your-subdomain>.workers.dev/api/analyze
```

`ALLOWED_ORIGIN` 已设置为你的 GitHub Pages 域名，避免其他人调用
该代理消耗你的 DeepSeek API 额度。本机开发时可设为
`http://127.0.0.1:8080`。

当前线上 Worker 地址：

```text
https://lingosu.online/cet6-listening-ai/api/analyze
```
